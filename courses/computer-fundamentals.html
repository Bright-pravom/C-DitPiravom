Course structure

Syllabus

Understand the computer interface, desktop tools, file management, and everyday navigation essentials.
Learn how to browse the web, use email effectively, evaluate online information, and work safely online.
Use word processing and common office tools to create documents and organize day-to-day tasks.
Build confidence with hands-on exercises that reflect real digital tasks in learning and work environments.

Practical Learning

Students work on real tasks including document creation, email usage, file management, and online research.
